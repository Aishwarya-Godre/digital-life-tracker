# Digital Life Tracker

A simple personal dashboard built with **HTML5** to organize daily goals, track habits, manage schedules, access useful websites, and write personal notes in one place.

## About the Project

Digital Life Tracker is a beginner-friendly web development project designed to help users organize their daily activities through a single webpage.

The project focuses on semantic HTML5, accessible forms, structured tables, and clean webpage organization.

## Features

- **Daily Goals:** Checklist for daily tasks and learning goals.
- **Habit Tracker:** Track habits across morning, afternoon, and evening.
- **Daily Schedule:** Organize activities by time and status.
- **Quick Links:** Access useful websites such as GitHub and LinkedIn.
- **Personal Notes:** Enter note titles and descriptions.
- **Accessible Structure:** Uses semantic HTML elements and form labels.

## Technologies Used

- HTML5
- Semantic HTML
- HTML Forms and Input Types
- Tables and Lists
- Accessibility Attributes

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the different dashboard sections.

## Learning Outcomes

- Understand the HTML5 document structure.
- Practise semantic elements such as `header`, `nav`, `main`, `section`, and `footer`.
- Create forms using `input`, `label`, and `textarea`.
- Organize information using tables and lists.
- Apply basic accessibility practices.

## Future Improvements

- Add CSS3 for a responsive and modern dashboard.
- Use JavaScript for live progress tracking.
- Save goals, habits, and notes with `localStorage`.
- Add dark mode and interactive charts.

## Current Limitations

This version uses HTML5 only. User progress and notes are not persistently saved, and the forms do not store submitted data.
